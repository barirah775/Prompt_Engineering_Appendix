# Ontology Structure

This folder contains the supporting files used to define, construct, and visualise the ontology described in the paper. The materials are organised into three subfolders:

## `01_structure`

Contains the raw CSV files used to define the underlying structure of the ontology. These files provide the source data from which the ontology components are constructed.

## `02_classes_and_relations`

Contains the definitions of the classes and relations used in the ontology, documenting the entities represented and the relationships between them.

## `03_knowledge_graphs`

Contains the knowledge graph figures and ontology visualisations presented in the paper. These figures provide visual representations of the ontology structure and its relationships.

Together, these files provide the underlying structural definitions and visual materials associated with the ontology presented in the paper.
