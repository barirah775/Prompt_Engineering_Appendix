# Template v1 — Exterior  
## Baseline Façade Generation Template

---

### Proposed Façade Template

**Key Opening Phrase**  
Realistic orthographic elevation

**Elevation Specification**  
(e.g. front elevation)

**Time Period**  
Corresponding to the previously generated floorplan

**Central Façade Description**  
Descriptive sentence defining façade composition, including:
- window style  
- door style  
- architectural period (e.g. Gothic, Classical, Victorian)

**Structure**  
Structural features derived from façade description (e.g. brickwork, stone dressings)

**Composition**  
Material palette used for construction

---

### Conditions / Negative Prompting

- Composition is symmetrical  
- Window rhythm matches the plan  
- Rendered in daylight with solar control  
- Orthographic projection  
- Realistic materials  
- No people or text  

**Optional Example Reference**  
If relevant, specify an example building that possesses the desired architectural features.
