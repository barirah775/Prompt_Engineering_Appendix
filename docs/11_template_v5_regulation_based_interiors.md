# Template v5 — Interior  
## Regulation-Based Derived Interior Template

This document records isometric building perspectives and applies Template v5 (Interior) to generate horizontal cross sections of the historical Sunday School reference façades.
The cross sections follow the BS 8888 and ISO 19650 architectural drawing standards.

Template version used:
- Interior template: ../templates/template_v5_interior.md

## Reference Façade Dataset

All interior derivations are based on the historical façade dataset recorded in:

`..docs/04_historical_reference_images.md`

Reference images are located in:

`..images/references/`

These reference façades act as the geometric and proportional ground truth for all interior
derivations.

### Ground Floor Cross Section — BS 8888

**Prompt:**

Generate the horizontal cross section for the ground floorplan of this building at 1 metre from the ground, following the BS 8888 graphical standards for architectural drawing.

(Window and door rhythm must match the façade image.)

**Output:**

![SS-01 Floorplan — BS 8888](../images/template_v5_outputs/floorplans_bs8888/ss_01_bs8888.png)
