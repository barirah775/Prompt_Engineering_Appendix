# Template v1 Baseline Validation — Historical Reference Reproduction

This document records façade and corresponding interior floorplans generated using  
**Template v1 — Exterior** and **Template v1 — Interior**.

The purpose of this  is to evaluate whether the baseline prompt template system
can reproduce known historical Sunday school buildings from the reference dataset.

These outputs form the baseline against which later template refinements are evaluated.
